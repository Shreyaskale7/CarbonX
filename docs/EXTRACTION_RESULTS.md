# Extraction results: consumption_kwh, baseline vs calibrated model

_Generated by `scripts/eval_extraction.py`. Do not edit by hand._

> **Synthetic data.** Every bill here is invented (`src/carbonx/extraction/synthetic.py`): fictional issuers, our own layouts. These numbers show how the pipeline behaves and that the evaluation is set up honestly. They are **not** accuracy on real Indian electricity bills. No real bill has been collected yet; when redacted bills arrive, this same script is re-run on them. Method, history and limits: `docs/EXTRACTION.md`.

**Setup.** 300 bills per layout. The model trains on 80% of layouts 1–5. Layouts 6–8 were unseen in training but were used for error analysis, so they are development data. **Layouts 9–11 were written after the model was frozen and are the test.** Confidence is temperature-scaled using leave-one-layout-out predictions on the training layouts, and may only be softened, never sharpened (T = 1.00). Leave-one-layout-out accuracy on the training layouts: 100.0%.
